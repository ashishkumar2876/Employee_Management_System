# Employee Management System

## About the Project
This is a simple console-based Employee Management System built using Java. It helps manage employee details such as ID, name, department, and salary.

The project uses a HashMap to store employee records and provides different options to add, update, remove, and view employees.

## Features
- Add a new employee
- Remove an employee using their ID
- Update employee details
- View employees by department
- Calculate the total salary of all employees
- Display details of all employees
- Handle errors when an employee ID already exists or does not exist

## Technologies Used
- Java
- HashMap
- Java Streams
- Exception Handling
- Scanner for user input

## How to Run

**1. Clone the repository**

```bash
git clone <your-repository-url>
```

**2. Open the project folder**

```bash
cd <project-folder>
```

**3. Compile the Java file**

```bash
javac Main.java
```

**4. Run the program**

```bash
java Main
```

Make sure Java is installed on your system before running the program.

## How It Works
When you run the program, a menu appears in the console. Enter the number corresponding to the operation you want to perform.

For example, you can add an employee by entering their ID, name, department, and salary. You can then update or remove that employee, filter employees by department, or calculate the total salary of all employees.

The program also checks for duplicate employee IDs and handles cases where an employee does not exist.
